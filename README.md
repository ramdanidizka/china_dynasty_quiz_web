# 🏮 China Dynasties Key Quest

Game edukasi kuis tentang sejarah dinasti Tiongkok, dibangun dengan Flutter untuk web.

## 🎮 Demo
[https://china-dynasty-quiz.vercel.app](https://china-dynasty-quiz.vercel.app)

## 📱 Fitur
- 5 level progresif
- 20 pertanyaan sejarah
- UI responsif untuk web
- Tema dinasti Tiongkok

## 🚀 Cara Menjalankan Lokal

### Prasyarat
- Flutter SDK (dengan web support)
- Chrome browser

### Langkah-langkah
```bash
# Clone repository
git clone https://github.com/username-anda/china-dynasty-quiz.git

# Masuk ke folder
cd china-dynasty-quiz

# Install dependencies
flutter pub get

# Jalankan di browser
flutter run -d chrome
